# 🚀 ServPortfolio - Asteroids Arena Server

Backend **Node.js + Express + Socket.IO** pour mon jeu multijoueur **Asteroids Arena**.  
Il gère les joueurs, les astéroïdes, les collisions et un **leaderboard en temps réel** 🏆.

---

## ⚡ Installation

```bash
git clone https://github.com/HenriMly/ServPortfolio.git
cd ServPortfolio
npm install
node server.js
